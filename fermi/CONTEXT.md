# Fermi estimation

Fermi is the suite's conditional calculator: it turns an authored formula and
selected input intervals into an output distribution and a value-of-information
ranking. It is not an evidence store or a decision-policy model.

## Language

**Assumption**:
A selected Fermi input interval that must hold for the estimate to hold.
_Avoid_: Fact, forecast

**Estimate**:
Fermi's conditional output distribution, given its assumptions and independent
sampling model. It is not a guarantee or a predicted decision outcome.

**Provenance receipt**:
A compact declaration of how an assumption entered Fermi: stated here, Gauge
room summary, data snapshot or one person's estimate. It does not certify the
input as evidence or calibrated.

**Elicited assumption**:
An input interval chosen from a Gauge room aggregate after explicit restatement
by the Fermi user. Its receipt retains pooling method, response count, round and
unit; it never claims the room's judgement is a calibrated real-world interval.

**Model variant**:
Fermi's A/B comparison of two input configurations. It is sensitivity analysis,
not mutually exclusive future states or a decision recommendation.

**Chance state**:
A mutually exclusive external state at decision time. Tree owns chance states;
Fermi can inform a payoff or input only through an explicit, auditable decision
model.
