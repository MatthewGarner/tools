    carry no verdict at all. Any other text becomes your line in its place — omit the key and the tool writes one

    style: field
    Field, Review, Decisions or Register. The view picker rewrites this same setting for the screen and exports. Review needs a saved comparison.
    font: DM Sans
    Chapter pairs editorial headings with DM Sans. DM Sans uses the same typeface throughout. Fonts are bundled in standalone exports.
    accent: #326752
    Your chart accent. palette: selects the shared colour palette; both stay in the source.

    Milestones

    Grid: Energisation 2027-02 .. 2027-06
    lane, label, then the honest range: P50 date .. P90 date (ISO days or months; a bare month means its middle). Any lane name works except Today and Verdict — those read as config keys
    Kickoff 2026-08 .. 2026-09
    no lane prefix → the unnamed lane
    FID 2026-09-30 [done]
    it happened — single date, solid marker. [risk] flags a milestone in trouble
    Vendor selection 2026-11
    a single undone date renders, but gets flagged ±? — false precision is visible, not forbidden. If the date really is fixed, say so
    Ofgem decision 2026-12-01 [fixed]
    a date you don’t control — an external event. Renders clean, and becomes the deadline the merge-risk line measures the plan against
    Lease ends 2027-02-28 [fixed] [lead: 6w]
    draws a DECIDE BY diamond six weeks before a fixed event. This is a decision clock: preserve the stated preparation time; it is not a delivery dependency or a promise that the decision will happen that day
    Audit 2026-10-12 .. 2026-11-23 [started: 2026-08-24]
    optional actual start, as a full calendar date. The quiet square and dotted connector show calendar span; the solid whisker still means P50–P90 finish. Select the item for elapsed time and duration. Never a planned start or progress percentage.

    About this timeline

    Timeline forecasts when milestones may finish. It does not decide which conditional work belongs in the plan; use Paths and Roadmap for those decisions.

    Finish ranges express uncertainty: P50 is the median forecast and P90 allows more time. A recorded start supplies calendar-span context, not a progress estimate. Fixed events and actual finishes retain their own marks.

    Snapshot before a review, then select it in History to compare forecasts. Snapshots stay in this browser.
