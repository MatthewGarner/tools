Paths

Plan the work that depends on answers you do not have yet.

Decision plan · all outcomes

Use Paths when a question can stop, pivot or expand investment. It keeps the possible plans visible until evidence resolves them.

Try:
    Syntax reference

    Config

    title: Habitat
    name the plan
    date: 2026-08-10
    date the artefact; use date: off to hide it
    today: 2026-08-10
    set the evaluation date instead of using the local date
    style: brief · style: question · style: conditions · style: agenda
    show the presentation brief (the default), one decision's outcome lens, the full decision-to-work logic, or the evidence work queue; overview and dependencies remain supported aliases
    verdict: off
    hide the verdict; any other text replaces the generated line
    palette: ocean
    choose ocean, slate, ember or plum
    accent: #C05621
    use a custom hex accent instead of the named palette

    Decisions

    decision groups:
    start a decision block; names use letters, numbers and hyphens
    question: Will people invite three friends?
    state the question to be answered
    signal: invites per active user
    name the evidence that will answer it
    reading: 2.4 invites per user
    record the latest reading
    learn: Run an unprompted invitation pilot with 100 people
    author the next deliberate move that will reduce this uncertainty
    enough: Yes at 3 invites each; no below 1; otherwise keep it open
    state in advance what evidence is sufficient to answer
    owner: Growth
    name who owns the answer
    answer-by: 2026-09-15
    set the answer deadline
    when: groups
    open this question only when another answer makes it relevant
    assume: yes 2026-09-16
    state the direction to follow after the deadline while the answer stays open
    answer: yes 2026-09-12 -- experiment 42
    close the question with an optional dated receipt

    Learning close-out

    Add this nested receipt to a decision with an answer or reading. It records what the author says may travel; it does not certify evidence or causality.

    close-out:
    start a selected-decision learning receipt; this does not create another whole-plan view
    basis-kind: observation
    choose observation, experiment, judgement, calculation or synthesis
    carry-forward: scoped-finding
    choose operating-claim, scoped-finding or no-carry-forward
    decision-use: keep the pilot narrow
    state how this may inform a later decision
    claim: Setup completers returned more often
    state the bounded, author-owned finding
    scope: New solo users in the pilot
    name the population, context and time boundary
    review-by: 2026-10-31
    set when the statement becomes review due
    reconsider-if: The matched pattern reverses
    state what would weaken the carry-forward statement
    next-check: Run an assigned variant
    name the next check before wider use
    review: / retirement:
    append dated challenge or retirement facts without overwriting the prior receipt

    Work

    Growth: Group challenges [risk] -- needs moderation
    an item line: lane, title, optional state, note and -> link
    [if groups] · [unless groups] · [if groups and pricing] · [if not groups]
    include work only on the named answer path; compound conditions use one operator
    NOW / NEXT / LATER
    start a period; period names are free text
