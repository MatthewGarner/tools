# Wardley map

Wardley map is a strategic landscape: a current, inspectable claim about value-chain
dependencies and evolution. Horizontal position is an authored evolution claim;
vertical order is a readable projection of `A -> B` (“A needs B”), with user needs
above the things they need. It is not a measured visibility axis. Positions are not
dates, forecasts, capacity plans, or decision outcomes. Snapshot compare makes
changing strategic claims auditable. Roadmap owns committed delivery; Paths owns
outcome-contingent investment decisions.
