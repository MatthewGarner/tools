# Pairwise Showdown

Pairwise Showdown records local priority judgements: between two contenders, which
comes first? Its Copeland order is an implied, provisional discussion record. A
direct comparison can settle neighbouring positions; a loop exposes incompatible
criteria rather than an error to hide.

It does not quantify value or probability (Tree), design conditional investment
(Paths), or schedule delivery (Roadmap). Its Markdown export must retain both the
current verdict and the per-position evidence state, so a partial ranking never
becomes a definitive priority list outside the tool.
